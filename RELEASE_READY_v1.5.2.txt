🐛 已修复的关键问题 (5项)
═══════════════════════════════════════════════════════════════

P1 - 阻断性问题 (3项):

1. NaïveProxy 认证错误
   影响: 所有 NaïveProxy 用户完全无法使用
   原因: 认证编码与上游 klzgrad/forwardproxy 不匹配
   修复: 按 [][]byte 正确编码，增加模块检查
   
2. 安装路径检测不一致  
   影响: NaïveProxy/AnyTLS/ShadowTLS/SS 后端
   原因: 检测用 PATH，启动用固定路径
   修复: 统一使用固定路径检测

3. ShadowTLS 后端端口冲突
   影响: 端口冲突导致服务无法绑定
   原因: 新增监听不检查已分配后端端口
   修复: 统一校验，原子回滚

P2 - 重要问题 (2项):

4. Mieru UDP 检测误判
   影响: UDP-only 端口显示错误状态
   修复: 按协议区分检测，UDP 需收到响应

5. 混合协议同步短路
   影响: Mieru 失败导致其他协议未处理
   修复: 收集失败继续处理，汇总报告

═══════════════════════════════════════════════════════════════
🛡️ 功能边界防护增强
═══════════════════════════════════════════════════════════════

新增 4 层防护（流量统计/月度配额/出站规则仅 Mieru）:

1. API 验证层
   → 拒绝非 Mieru 正数 trafficLimit，返回 400

2. 数据处理层
   → updatePortTraffic() 过滤非 Mieru 流量

3. 前端交互层
   → 点击流量管理显示 toast 提示

4. UI 展示层
   → 显示"暂不支持"，隐藏流量设置选项

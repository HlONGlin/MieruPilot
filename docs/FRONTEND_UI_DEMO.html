API 示例

获取支持的代理类型

GET /api/proxy-types

添加 NaïveProxy 端口

POST /api/nodes/:id/ports { "port": 443, "protocol": "tcp", "username": "user123", "password": "pass123", "proxyType": "naive", "domain": "example.com", "autoACME": true }

上传 TLS 证书

POST /api/nodes/:id/ports/:portID/upload-cert Content-Type: multipart/form-data

生成 Clash 订阅

GET /api/subscription/clash

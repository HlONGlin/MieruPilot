## 📖 快速开始

### 下载安装

```bash
# 下载 Manager
wget https://github.com/HlONGlin/UnifiedProxy/releases/download/v1.4.0/merit-manager-linux-amd64
chmod +x merit-manager-linux-amd64
sudo mv merit-manager-linux-amd64 /usr/local/bin/merit-manager

# 下载 Agent
wget https://github.com/HlONGlin/UnifiedProxy/releases/download/v1.4.0/merit-agent-linux-amd64
chmod +x merit-agent-linux-amd64
sudo mv merit-agent-linux-amd64 /usr/local/bin/merit-agent
```

### 启动服务

```bash
# 启动 Manager
merit-manager --port 8080

# 访问 Web UI
open http://localhost:8080
```

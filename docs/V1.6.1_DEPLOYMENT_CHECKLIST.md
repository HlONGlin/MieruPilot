## 🚀 部署步骤

### 1. 准备阶段

```bash
# 1.1 备份当前版本
mkdir -p ~/backup/v1.6.0
cp /usr/local/bin/merit-manager ~/backup/v1.6.0/
cp -r /var/lib/merit ~/backup/v1.6.0/

# 1.2 下载新版本
cd /tmp
wget https://github.com/HlONGlin/MieruPilot/releases/download/v1.6.1/merit-manager-linux-amd64
wget https://github.com/HlONGlin/MieruPilot/releases/download/v1.6.1/SHA256SUMS_v1.6.1

# 1.3 验证校验和
sha256sum -c SHA256SUMS_v1.6.1
```

### 2. Manager 升级

```bash
# 2.1 停止服务
systemctl stop merit-manager

# 2.2 替换二进制
mv /tmp/merit-manager-linux-amd64 /usr/local/bin/merit-manager
chmod +x /usr/local/bin/merit-manager

# 2.3 验证版本
/usr/local/bin/merit-manager --version

# 2.4 启动服务
systemctl start merit-manager

# 2.5 检查状态
systemctl status merit-manager
journalctl -u merit-manager -f
```

### 3. 功能验证

```bash
# 3.1 访问面板
curl -I http://localhost:8080

# 3.2 检查证书监控日志
journalctl -u merit-manager | grep "证书"

# 3.3 调用新增 API
curl http://localhost:8080/api/certificates/expiring

# 3.4 检查节点列表版本信息
# 打开面板 -> 节点列表 -> 查看 Agent 版本
```

### 4. Agent 升级 (可选)

```bash
# 4.1 在面板中获取升级命令
# 节点详情 -> 安装命令

# 4.2 在节点上执行
curl -fsSL 'http://manager-url/install.sh?key=xxx' | sudo bash

# 4.3 验证版本
merit-agent --version
systemctl status merit-agent
```

### 5. 回滚计划 (如果需要)

```bash
# 5.1 停止新版本
systemctl stop merit-manager

# 5.2 恢复旧版本
cp ~/backup/v1.6.0/merit-manager /usr/local/bin/

# 5.3 恢复数据 (如果数据损坏)
systemctl stop merit-manager
cp -r ~/backup/v1.6.0/merit/* /var/lib/merit/

# 5.4 启动旧版本
systemctl start merit-manager
```

## 🐛 已知问题处理

### 问题 1: Manager 启动失败

**症状**: systemctl start merit-manager 失败

**检查**:
```bash
journalctl -u merit-manager -n 50
```

**解决**:
- 检查端口占用 (8080)
- 检查数据目录权限
- 检查配置文件格式

### 问题 2: 版本信息不显示

**症状**: 面板不显示版本兼容性信息

**检查**:
```bash
# 检查 Agent 版本上报
journalctl -u merit-agent | grep "report"

# 检查 Manager 日志
journalctl -u merit-manager | grep "version"
```

**解决**:
- 升级 Agent 到最新版本
- 清除浏览器缓存
- 重启 Manager 服务

### 问题 3: 证书监控不工作

**症状**: 没有证书监控日志

**检查**:
```bash
# 检查是否有 NaïveProxy 端口
# 检查证书是否手动上传 (非 ACME)
```

**解决**:
- 确认有手动上传的证书
- 等待 6 小时后查看日志
- 检查证书是否即将过期 (>30天不会告警)

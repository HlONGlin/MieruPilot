## ✅ 已实现功能

### C1. Agent 版本兼容性检查

**目标**: 防止 Manager 与 Agent 版本不一致导致的功能异常

**实施内容**:

1. **版本解析和兼容性检查** (`internal/version/version.go`)
   - 支持语义化版本解析 (v1.6.0, 1.6.1-rc1等)
   - 兼容性规则: 主版本号必须相同,次版本号差距≤1
   - 自动提取 buildinfo 中的版本号

2. **Agent 报告时检查** (`internal/manager/agent_api.go`)
   - Agent 每次报告状态时自动检查版本
   - 不兼容时记录到 `LastError` 并在面板显示
   - 返回升级建议给 Agent

3. **前端展示** (DTO层)
   - 新增字段:
     - `versionCompatible`: 版本是否兼容
     - `upgradeRecommended`: 是否建议升级
     - `compatibilityError`: 兼容性错误信息
   - 节点列表、详情页面均包含版本状态

**测试覆盖**:
```bash
cd internal/version
go test -v
# 全部测试通过 ✅
```

**API变更**:
- `/api/agent/report` 响应增加:
  ```json
  {
    "ok": true,
    "managerVersion": "1.6.1",
    "upgradeRecommended": false,
    "message": "建议升级 Agent 到最新版本"
  }
  ```

- 节点 DTO 增加版本兼容性字段:
  ```json
  {
    "versionCompatible": true,
    "upgradeRecommended": false,
    "compatibilityError": ""
  }
  ```

### B1. 证书到期监控

**目标**: 主动监控手动上传的证书到期时间,避免服务中断

**实施内容**:

1. **证书到期检查** (`internal/manager/cert_monitor.go`)
   - 监控所有手动上传的 NaïveProxy 证书
   - 跳过 ACME 自动续期的证书
   - 分级告警:
     - `expired`: 已过期
     - `critical`: 7天内过期
     - `warning`: 30天内过期
     - `valid`: 正常

2. **后台监控服务**
   - 每 6 小时扫描一次所有证书
   - 检测到即将过期的证书时记录日志
   - 自动在 Manager 启动时启动监控

3. **API 端点**
   - `GET /api/certificates/expiring`: 获取需要关注的证书列表

**示例响应**:
```json
[
  {
    "nodeId": "abc123",
    "nodeName": "节点1",
    "portId": "port456",
    "port": 443,
    "domain": "example.com",
    "expiresAt": "2024-12-25T00:00:00Z",
    "daysUntilExpiry": 7,
    "level": "critical",
    "message": "即将过期（7 天后）"
  }
]
```

**日志输出**:
```
ℹ️  证书需要续期 [节点: 节点1, 端口: 443, 域名: example.com] - 即将过期（25 天后）
⚠️  证书即将过期 [节点: 节点2, 端口: 443, 域名: example2.com] - 即将过期（5 天后）
⚠️  证书已过期 [节点: 节点3, 端口: 443, 域名: example3.com] - 已过期（2 天前）
```

## 🔄 升级指南

### 从 v1.6.0 升级

1. **Manager 升级**
   ```bash
   # 下载新版 Manager
   wget https://github.com/HlONGlin/MieruPilot/releases/download/v1.6.1/merit-manager-linux-amd64
   
   # 停止旧版
   systemctl stop merit-manager
   
   # 替换二进制
   mv merit-manager-linux-amd64 /usr/local/bin/merit-manager
   chmod +x /usr/local/bin/merit-manager
   
   # 启动新版
   systemctl start merit-manager
   ```

2. **Agent 升级** (建议但非必须)
   ```bash
   # 使用面板的一键升级命令
   # 或手动执行:
   curl -fsSL 'http://manager-url/install.sh?key=your-key' | sudo bash
   ```

3. **验证升级**
   - 打开面板,查看节点列表
   - 检查版本兼容性状态
   - 查看 `/api/certificates/expiring` 是否有告警

### 兼容性说明

- ✅ **向后兼容**: v1.6.1 Manager 可以管理 v1.5.x 和 v1.6.x Agent
- ✅ **数据库兼容**: 无需迁移数据库
- ✅ **配置兼容**: 无需修改现有配置
- ⚠️ **Agent v1.4.x**: 不兼容,必须升级到 v1.5.0+

## 📝 配置示例

### 启用证书监控日志

默认已启用,无需额外配置。日志输出到标准输出:

```bash
# 查看证书监控日志
journalctl -u merit-manager | grep "证书"
```

### 调整监控间隔

如需修改默认的 6 小时检查间隔,修改 `internal/manager/server.go`:

```go
// 改为每 12 小时检查一次
go s.MonitorCertificates(12 * time.Hour)
```

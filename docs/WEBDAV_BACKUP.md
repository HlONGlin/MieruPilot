# WebDAV 云备份

本功能将 MieruPilot / UnifiedProxy 的管理配置备份到**外部已有 WebDAV 服务**，例如自建 Nextcloud 或其他支持 WebDAV 的私有云盘。本项目不提供 `/dav/` 文件服务，不新增同步账号，也不占用新的监听端口。

## 使用

1. 更新并启动新版 Manager，打开 **系统设置 → WebDAV 云备份**。
2. 填写最终 WebDAV **目录地址**、云盘用户名和密码（优先使用云盘应用密码）。例如 `https://cloud.example.com/remote.php/dav/files/用户名/MieruPilot/`。具体地址以云盘提供的 WebDAV 入口为准。
3. 保存配置，再点“测试连接”。测试会在该目录上传、下载并删除一个唯一的小测试文件。
4. 点“立即备份”，将当前节点管理数据上传为独立 JSON 文件，再下载逐字节验证。
5. 点“查看云端备份”，选择历史文件，确认后恢复。恢复会替换节点配置、生成本地恢复前副本，并保留当前管理员、面板地址和云备份连接配置；随后同步节点。

当前仅支持**手动备份与恢复**，不执行自动双向同步、不自动恢复、不自动删除历史文件。云端文件名采用 UTC 时间戳和随机后缀，每次新建文件，不覆盖上一次备份。列表只显示该目录下符合本项目命名规则的备份。

## 配置与连接

- 目录须填写完整最终地址，不使用分享链接、目录页面或带账号密码/查询参数的 URL。重定向会被拒绝，防止凭据和备份转发到错误目标。
- 如果末级目录不存在，连接测试和上传会尝试 MKCOL 创建它；其父目录须提前存在。建议使用独立的私有备份目录。
- 默认要求 HTTPS，并使用系统信任链校验证书；不会关闭 TLS 校验。可信内网可明确选择“允许 HTTP”，但 HTTP 会明文传输凭据和备份。
- 密码留空保留原密码；修改地址或用户名时须重新输入密码，避免无意将旧凭据发送到新地址。可选择“清除已保存密码”。
- 每个远端 HTTP 请求最长 45 秒，目录响应最大 2 MiB，备份最大 16 MiB，与本地导入上限一致。
- 使用 Basic 认证；需要 OAuth、交互登录或仅支持特定厂商扩展的服务不在本次范围。

## 备份内容与凭据

备份沿用原有 JSON 导出格式，包含节点/端口账号、出站凭据、TLS 证书与私钥、订阅令牌，以及原导出格式中的管理信息与审计记录；不包含待执行临时任务。请仅保存到受信任的私有目录。备份本身未额外加密，HTTPS 只保护传输。

云盘连接凭据需要用于后续请求，因此保存在服务器本地私有 JSON 数据文件中，**不进行哈希、不承诺静态加密**；管理接口仅返回是否已保存密码，任何导出/云端备份均排除云盘连接配置。数据文件沿用 `0600` 写入权限（Windows 需同时确保账户 ACL）。

恢复旧版本备份不会清除当前云备份配置。首次迁移到新 Manager 时，需要重新填写云盘连接信息。

## 错误处理

- 401/403：检查账号、应用密码和目录读写权限。
- 404/409：检查完整目录地址与父目录是否存在。
- 3xx：填写服务端最终 WebDAV 地址，避免入口跳转。
- 507：检查云盘配额。
- 上传后校验失败：面板会报错并显示文件名，请勿将该文件用于恢复；历史备份不会被覆盖。
- 无效 JSON、错误节点/端口或出站配置、超限备份会在恢复前拒绝，不更改当前节点。

节点备份不包含 Agent 的二进制文件、进程状态或系统服务定义。恢复后仍须保持现有 Agent 与 Manager 的网络连接可用。
